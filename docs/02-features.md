# Out of MVP

The following features are intentionally excluded from Version 1:

- AI Assistant
- Chat
- Video Meetings
- Payroll
- HR Module
- CRM
- Client Portal
- Calendar
- Third-party Integrations

These features will be considered after the MVP is completed.
